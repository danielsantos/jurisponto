Política de Privacidade

Versão 2026-08-22 · Última atualização: 22 de agosto de 2026.

Modelo operacional sujeito à revisão jurídica antes de divulgação pública ou tratamento de dados reais.

Dados tratados

Tratamos dados de cadastro, autenticação, usuários, clientes, casos, documentos, agenda, financeiro e registros de segurança necessários à operação da plataforma.

Finalidades

Os dados são usados para disponibilizar a plataforma, controlar acessos, organizar os atendimentos, enviar comunicações solicitadas, prevenir fraudes, manter auditoria e cumprir obrigações legais aplicáveis.

Compartilhamento e segurança

O acesso é restrito ao escritório responsável pelos dados e a perfis autorizados. Arquivos exigem autenticação para download. Prestadores essenciais podem tratar dados somente conforme instruções e contratos aplicáveis.

Retenção e direitos

Os dados são mantidos enquanto necessários às finalidades informadas ou a obrigações legais. Você pode solicitar confirmação, acesso, correção, anonimização, bloqueio, eliminação, informação sobre compartilhamento ou revisão de consentimento.

Registrar solicitação relativa a dados pessoais.

Contato

Para exercer direitos ou reportar um incidente, use o canal de solicitações acima. O responsável pelo tratamento deverá responder nos prazos aplicáveis.
